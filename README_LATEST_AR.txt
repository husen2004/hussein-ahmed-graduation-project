مشروع تخرج حسين أحمد 2026
================================================

الطالب: حسين طارق حسين أحمد
الرقم الجامعي: 1320222455

طريقة التشغيل على Windows:
1) فك الضغط عن الحزمة كاملة.
2) ثبّت Python 3 إن لم يكن موجوداً.
3) شغّل START_OFFLINE.bat.
4) افتح http://127.0.0.1:8000

حسابات العرض:
عيّن كلمات مرور جديدة باستخدام tools/set_admin_password.py قبل النشر.

قاعدة البيانات المرفقة تحتوي بيانات تجريبية وهمية فقط.
غيّر كلمات المرور قبل أي استخدام غير تجريبي.

أبرز الوظائف:
- إدارة الطلبة وأولياء الأمور والأرشفة مع سبب وملاحظة.
- صف أساسي وعضويات دراسية إضافية.
- رسوم شهرية: مسدد / جزئي / غير مسدد.
- سند الدفع يبقى مسودة ولا يعتمد إلا عند تأكيد الطباعة.
- سجل مستقل للديون النقدية ودفعاتها.
- الحضور والعلامات والتقارير.
- إعداد قوائم رسائل يدوية بعد المراجعة والتأكيد.

مهم: لا يوجد إرسال SMS تلقائي ولا اتصال ببوابة رسائل.
للتعليمات التفصيلية افتح USER_GUIDE_AR.md.
للنشر السحابي على PythonAnywhere افتح DEPLOY_PYTHONANYWHERE_AR.md.
