# 🎓 نظام إدارة الطلاب
## Student Management System

---

## 📋 وصف البرنامج

نظام متكامل لإدارة بيانات الطلاب والأيتام وأولياء الأمور والمساعدات والمدارس.

---

## ✅ مميزات النظام

- **إدارة الطلاب**: إضافة، تعديل، حذف، بحث
- **استيراد الطلاب من Excel**: تنزيل قالب جاهز، تعبئته، ثم رفعه ليقوم النظام بإضافة كل الطلاب تلقائياً
- **إدارة الصفوف الدراسية**: إضافة صف جديد، تعديل اسم صف موجود، أو حذفه (إن لم يكن فيه طلاب)
- **تصفير الحساب المالي**: زر لتصفير المبلغ المدفوع لكل الطلاب دفعة واحدة، أو لطالب واحد بعينه (الرسوم المطلوبة تبقى كما هي)
- **رقم طالب تسلسلي** يتولد تلقائياً (يبدأ من 1001 ويزيد تباعاً، ولا يتكرر أبداً)
- **الرسم الشهري المطلوب**: حقل خاص بكل طالب، قابل للتعديل السريع من قائمة الطلاب وصفحة عرض بياناته
- **منع تكرار رقم الهوية**
- **أولياء الأمور**: ربط كل طالب بأولياء أمره، مع **إضافة تلقائية لولي الأمر** عند تسجيل الطالب (يُستخرج الاسم من الجزء الثاني والثالث والرابع من اسم الطالب)
- **الحالة الاجتماعية للطلاب**: قائمة موسّعة (يتيم الأب / الأم / الأبوين، الأبوين منفصلين، أحد الوالدين مغترب أو أسير، أسرة فقيرة، وغيرها) بدلاً من نوع اليتم المحدود سابقاً
- **حالة الطالب الشاملة**: عند عرض بيانات أي طالب (من صفحة الطلاب أو من صفحة أولياء الأمور) تظهر 3 حالات أسفل حالة الطالب: **الحالة الصحية** (سليم / مرض مزمن / إعاقة...)، **الحالة الاجتماعية** (يتيم وما شابه)، و **الحالة المادية** (5 تصنيفات: ميسورة الحال، متوسطة الحال، دون المتوسط، فقيرة، فقيرة جداً). يمكن تعديل الثلاثة معاً من تبويب "🗂️ حالة الطالب" في نافذة عرض الطالب
- **مرحلة الروضة**: تمت إضافة 3 صفوف جديدة (مستمع - مواليد 2023، بستان - مواليد 2022، تمهيدي - مواليد 2021) قبل الصف الأول
- **المدارس**: إدارة قائمة المدارس والمحافظات
- **المساعدات**: تتبع المساعدات المالية والعينية
- **صورة الإشعار**: إمكانية إرفاق صورة عند إضافة الرسوم، وأيضاً عند تسجيل الدفعة نفسها من نافذة "تسجيل دفعة" — تظهر تلقائياً على سند القبض المطبوع
- **الحضور والغياب اليومي**: قائمة جديدة لتسجيل حضور/غياب/تأخر/استئذان كل طالب يومياً حسب الصف والتاريخ، مع إمكانية "تحضير الكل" دفعة واحدة، وحفظ الحضور لكل طلاب الصف بضغطة واحدة، وشارات إحصائية سريعة (عدد الحاضرين/الغائبين/المتأخرين/المستأذنين/غير المسجَّلين) لكل يوم
- **صلاحية إغلاق إدخال العلامات**: يستطيع مدير النظام فتح أو إغلاق إدخال العلامات لكل معلم بشكل مستقل، مع منع الحفظ من الواجهة والخادم عند الإغلاق.
- **حضور وغياب المعلم**: يستطيع المعلم تسجيل حضور وغياب طلاب الصفوف والشُعب المسموحة له.
- **سجل النشاطات**: زر داخل قائمة المستخدمين يعرض سجل تسجيل الدخول والعمليات التي نفذها كل مستخدم مع التاريخ والوقت.
- **مشروع التخرج**: تبويب داخل بطاقة كل طالب لتسجيل عنوان المشروع، الوصف، المشرف، الحالة، العلامة، تاريخ التسليم والملاحظات.
- **التقارير**: طباعة كشوف متعددة
- **لوحة تحكم** مع إحصائيات ورسوم بيانية
- **واجهة عربية** كاملة من اليمين لليسار
- **قاعدة بيانات SQLite** (ملف واحد، لا يحتاج سيرفر)

## 🖥️ متطلبات التشغيل

- **Python 3.8** أو أحدث
- مكتبة **openpyxl** (مطلوبة فقط لميزة استيراد/تصدير الطلاب من Excel)

للتحقق من وجود Python:
```
python --version
```

لتثبيت المكتبة المطلوبة (مرة واحدة فقط):
```
pip install openpyxl
```

إذا لم يكن Python مثبتاً، حمّله من:
> https://www.python.org/downloads/

## 🔍 البحث الذكي

مربع البحث في صفحة "إدارة الطلاب" أصبح بحثاً ذكياً: اكتب أي كلمة وسيبحث تلقائياً في كل الحقول التالية معاً:
- اسم الطالب
- رقم الطالب (التسلسلي)
- رقم الهوية
- رقم الجوال (الأول والثاني)
- اسم ولي الأمر
- المدرسة
- الصف الدراسي
- الجنس
- الحالة الاجتماعية (يتيم الأب / الأم / الأبوين ... إلخ)
- حالة الطالب (نشط / موقوف / منسحب / متخرج)

عند كتابة أكثر من كلمة (مثال: "احمد الثاني عشر") يبحث النظام عن طالب تتحقق فيه كل الكلمات معاً، وكل كلمة يمكن أن تُطابق أي حقل من الحقول أعلاه.

## 🧰 الفلترة المتقدمة للطلاب

صفحة "إدارة الطلاب" تحتوي على صف فلاتر إضافي يمكن الجمع بينها معاً (وأيضاً مع مربع البحث) للوصول إلى مجموعة طلاب دقيقة:

- **الجنس** / **الصف** / **الحالة** (نشط، موقوف...) — الفلاتر الأساسية
- **المدرسة** — حسب المدارس المسجَّلة في النظام
- **الشعبة** — حسب الشُعب الفعلية المستخدمة في التسجيلات
- **المحافظة**
- **الحالة الصحية** — حسب التصنيف الصحي المسجَّل من تبويب "🗂️ حالة الطالب" (مع خيار "سليم / لا يوجد")
- **الحالة الاجتماعية** — حسب التصنيف الاجتماعي (يتيم الأب / الأم ... إلخ) مع خيار "لا يوجد / طبيعية"
- **الحالة المادية** — حسب التصنيفات الخمسة (ميسورة الحال ... فقيرة جداً)

زر **🧹 مسح الفلاتر** يعيد جميع الفلاتر ومربع البحث إلى وضعها الافتراضي دفعة واحدة.

## 📤 تصدير التقارير

كل صفحة تحتوي على جدول بيانات (قائمة الطلاب، أولياء الأمور، الحالة الاجتماعية، الرسوم الشهرية، التقارير والإحصاء، المستخدمون، علامات الطلاب) تحتوي الآن على أزرار تصدير في أعلى الجدول:

- 📗 **Excel** — يُصدَّر الجدول كملف `.xls` يفتح مباشرة في Excel.
- 📄 **CSV** — ملف نصي مفصول بفواصل، متوافق مع Excel وأي برنامج جداول بيانات.
- 📘 **Word** — يُصدَّر الجدول كملف `.doc` يفتح مباشرة في Word.
- 🧾 **PDF** — يفتح نافذة طباعة منسّقة؛ اختر "حفظ كـ PDF" (Save as PDF) من نافذة الطباعة لحفظ الملف.

هذه الميزة تعمل بالكامل من داخل المتصفح بدون الحاجة لاتصال إنترنت أو مكتبات إضافية.

## 🔔 الإشعارات الذكية

أيقونة الجرس 🔔 أعلى يمين الشاشة تعرض تنبيهات تلقائية تُحدَّث كل 5 دقائق:

- ⏰ **اقتراب موعد الاستحقاق**: طلاب تبقى أسبوع أو أقل على موعد دفع رسومهم (الرسوم الإضافية ذات تاريخ استحقاق محدد، أو الرسم الشهري القريب من نهاية الشهر) وما زالت غير مسددة.
- 💰 **عدم تسديد الرسم الشهري قبل يوم 10**: ابتداءً من اليوم 11 من كل شهر، يُنبّه النظام تلقائياً عن كل طالب لم يسدد رسمه الشهري لذلك الشهر بعد.
- 🔴 **متأخرون في الدفع**: طلاب لم يسددوا الرسم الشهري منذ 4 أشهر فأكثر.
- ⚠️ **بدون ولي أمر**: طلاب لا يوجد لهم أي ولي أمر مسجَّل في النظام.

الضغط على أي إشعار ينقلك مباشرة إلى بيانات الطالب المعني.
